# 实验助手 · 局域网互传 使用说明

> 同一 Wifi 下，用浏览器在手机 / 平板 / 电脑之间互传**实验文件与文本**。
> 数据只在你自己的局域网内流动，不经过任何云服务、不需要账号、不需要联网。
> 入口：实验助手左侧导航 / 底部 Tab 的 **「局域网互传」**（路由 `#/lan`）。

---

## 1. 快速开始

1. 确认运行服务的那台设备装了 **Python 3**（3.7 及以上即可，**无需 pip 安装任何东西**）。
2. 双击 `start-lan.bat`（Windows）或执行 `./start-lan.sh`（Linux / macOS）。
3. 终端会打印地址，例如：

   ```
   本机访问          : http://127.0.0.1:8000
   同一Wifi下其他设备 : http://192.168.1.23:8000
   ```

4. 其他设备连同一个 Wifi，用浏览器打开**第二个**地址 → 进入实验助手 → 点「局域网互传」，页面会自动连上服务端。
5. 若本机是**双击 `index.html`** 打开的（`file://`），在互传页的「服务端地址」里填 `http://192.168.1.23:8000`，点「连接服务端」即可（服务端已开放跨域，地址会被记住，下次自动连）。

> 手机可以不用装任何 App：浏览器打开地址就能用，还能顺便用「记录模式」拍照记录实验。

---

## 2. 能做什么

| 能力 | 说明 |
|---|---|
| 多文件上传 | 拖拽到虚线框，或点击选择；支持一次多个 |
| 进度与速度 | 每个文件一条进度条，显示百分比与实时速度 |
| 大文件分片 | 默认 4 MB 一片，可中断后续传（只补缺失分片） |
| 同名秒传 | 文件指纹一致且服务端已有 → 直接跳过传输 |
| 共享文件列表 | 名称 / 大小 / 时间，支持下载与删除 |
| 文本互传 | 全局一条最新文本（注意事项、链接），可一键复制 |
| **下载即导入** | 在列表里点**「下载」**时，实验 `.json` **自动进「我的实验」**（见 §2.1） |
| 手机端可缩放 | 页面支持**双指缩放**，清单与地址可以放大看清 |
| 浅色 / 深色 | 跟随实验助手主题，手机端自动单栏 |

### 2.1 下载即导入（点「下载」就顺手进「我的实验」）

不管你是服务端还是连过去的一端，**在共享文件列表里点「下载」**这一下既是下载、也是导入：

| 点下载的文件 | 行为 |
|---|---|
| 实验助手导出的实验包 `.json`（`{"kind":"zhbit-lab-experiment", exp}`） | 正常下载，并导入「我的实验」，名字后加「（互传导入）」，报告一并带过来 |
| 「导出全部实验」的备份包 `.json`（`{"kind":"zhbit-lab-backup", exps[]}`） | 逐个导入 |
| 大模型生成的裸实验 JSON（直接是 `{name, subject, steps[]}`） | 自动补齐为合法实验后导入 |
| 图片 / PDF / 视频 / 压缩包等非 `.json` | **不处理**（互传本来就要传各种文件，只有下载本身生效） |
| 认不出的 `.json`（损坏、结构不对、超过 20MB） | **明确报错**：互传页「下载即导入」卡片 + 首页红色横幅 + 提示条，三处都能看到 |

- 导入的每个实验都会**分配新 id**，不会覆盖本机已有的实验；同一文件（按文件指纹）再下一次只会提示「之前已导入过」。
- **没有后台监听、没有轮询**：不点下载就什么都不会发生；服务端不用停在这一页。
- 记录可随时在互传页「下载即导入」卡片里清空；报错记录清掉后首页横幅随之消失。
- 手机端页面可以**双指缩放**（浏览器直接支持；打包成 App 时已在 Android WebView 侧打开内置缩放）。

## 3. 文件存在哪

运行服务端那台设备的：

```
实验助手demo/
└─ lan-transfer/
   ├─ uploads/       ← 收到的完整文件（磁盘上以 id 命名，原名记在 files.json）
   ├─ .chunks/       ← 上传中的分片（可安全删除）
   ├─ files.json     ← 文件索引（id → 原名 / 大小 / 时间）
   └─ clip.json      ← 文本剪贴板
```

想换个目录：`python lan-server.py --data D:\互传资料`。

## 4. 常见问题

**打不开页面？**
- 两台设备要在同一个 Wifi，且不是「访客网络 / AP 隔离」。
- Windows 首次启动会弹防火墙提示，请选择「允许访问专用网络」。
- 用地址栏里的**局域网 IP**（`192.168.x.x` / `10.x.x.x`），不要用 `127.0.0.1`。
- 互传页显示「未连接」：点「连接服务端」重试；确认服务端仍然在运行。

**端口被占用？**
```bash
python lan-server.py --port 9000
```

**能传到公网吗？**
不能，也不建议：本工具**无鉴权**，局域网内任何能访问该地址的设备都能上传 / 下载 / 删除。请勿把端口暴露到公网。

**换台电脑运行服务端，之前的文件还在吗？**
在原来那台设备上（`lan-transfer/uploads/`）。把 `lan-transfer/` 整个拷过去即可继续共享。

## 5. 接口一览（自研对接 / 二次开发用）

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/` | 返回单文件实验助手 HTML |
| GET | `/api/server-info` | 局域网 IP、端口、分片大小、文件数 |
| GET | `/api/files` | 文件列表 |
| GET | `/api/download?id=` | 流式下载（带原始文件名） |
| DELETE | `/api/files?id=` | 删除文件 |
| POST | `/api/upload/init` | `{name,size,lastModified}` → `{id,chunkSize,totalChunks,uploaded,done}` |
| POST | `/api/upload/chunk?id=&index=` | 原始字节分片，原子落盘 |
| GET | `/api/upload/status?id=` | 查询已传分片（外部断点续传用） |
| POST | `/api/upload/complete` | `{id}` → 按序合并落盘 |
| GET / POST | `/api/clip` | 读取 / 写入文本剪贴板 |

所有响应带 `Access-Control-Allow-Origin: *`，并支持 `OPTIONS` 预检，所以 `file://` 打开的单文件页面也能直连。

## 6. 自检

```bash
node src/tools/check-lan.mjs     src/index.html   # 真实启动服务端，33 项接口断言
node src/tools/check-page.mjs    src/index.html   # 页面静态验收 153 项（工作区含课程素材时 155 项）
node src/tools/check-isotope.mjs src/index.html   # 同位素左上标渲染校验 25 项
```

> 三套都要求「失败 0」。`check-lan.mjs` 会自己在临时目录里起服务端、跑完自动清理，不会污染仓库。
