# 珠科 × 华为云「码道 Agent 创新赛」参赛作品仓库

> 本仓库为 **华为开发者大赛 · 珠海科技学院华为云码道 Agent 创新赛** 的参赛作品仓库骨架。
> 作品基于 **华为云码道 CodeArts** 编程智能体开发，作品形态为可运行、可复现的 Web 应用 / 小程序 / 桌面工具。

**⏰ 报名截止 2026-10-23（周五）** —— 倒计时与阶段安排见 [`docs/作战计划.md`](docs/作战计划.md)。

---

## 快速开始

1. 把作品源码放进 `src/`（或按你的工程结构另建目录，但要同步更新本 README）。
2. 在 `docs/作品说明.md` 里补全：作品用途、目标用户、核心功能、界面风格。
3. 把码道使用痕迹补齐到 `.evidence/`（**这是提交的硬性材料**）。
4. 按 `docs/提交清单.md` 自检后，打包上传到大赛官网作品提交入口。

```bash
git clone <本仓库地址>
cd <仓库目录>
# TODO: 作品启动命令（例如 npm install && npm start）
```

## 参赛要点（摘自赛事推文）

- **报名截止**：10 月 23 日，截止后不可修改队员与队名。
- **组队规则**：2–5 人一组，每人仅可加入 1 支队伍，支持跨专业组队，可配 1 名指导老师；每件作品仅可由 1 支队伍推报。
- **开发要求**：开发过程必须使用 **华为云码道 CodeArts** 作为核心 AI 编程工具。
- **作品要求**：须原创、可运行、可复现；禁止提交毕业设计、课程论文、已获国家级奖项或国际竞赛获奖作品。
- **提交材料**：作品压缩包 + 码道使用痕迹证明（IDE 日志 / AI 对话与 Prompt 截图 / 代码生成重构排错记录）。
- **命名格式**：`作品名称+队伍名称+版本号+联系方式.zip`。

完整信息见 [`docs/赛事关键信息.md`](docs/赛事关键信息.md)。
