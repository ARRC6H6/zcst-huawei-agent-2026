# 码道使用痕迹证明

> ⚠️ **提交必需材料**。赛事要求：须提交码道使用痕迹证明材料，包括但不限于
> ① IDE 插件使用日志与操作记录；② AI 交互对话与 Prompt 截图；③ 代码生成、重构、排错过程记录。

---

## 目录约定

| 目录 | 放什么 | 建议格式 |
| --- | --- | --- |
| `01-ide-plugin-logs/` | 码道 IDE 插件的使用日志、操作记录、导出记录 | `.log` / `.txt` / `.md` / 截图 |
| `02-ai-prompts/` | 与码道的 AI 交互对话与 Prompt 截图 | `.png` / `.jpg`（命名成对：`001-prompt.png` / `001-reply.png`） |
| `03-codegen-history/` | 代码生成、重构、排错的过程记录 | `.md` 流水 + 前后对比截图 |

---

## 命名建议

```
01-ide-plugin-logs/
  2026-09-01_codearts-login-and-init.md

02-ai-prompts/

03-codegen-history/

```

---

## 隐私与合规

- 截图前**打码**：个人信息、真实姓名以外的隐私、API Key、Token、内网地址。
- 不要放入他人版权素材、他人代码。
- 痕迹材料要能看出是**本项目**的开发过程（能看到项目名 / 文件路径最好）。
