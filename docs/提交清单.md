# 提交前自检清单

> 每次提交前照着过一遍。初赛每支队伍**每天最多 1 次**提交，别浪费机会。

---

## 一、内容自检

- [ ] 作品为原创，未使用毕业设计、课程论文、已获国家级奖项或国际竞赛获奖作品
- [ ] 开发过程全程使用 **华为云码道 CodeArts** 作为核心 AI 编程工具
- [ ] 作品**可运行、可复现**（在干净环境按 README 走一遍能跑起来）
- [ ] `docs/作品说明.md` 已填写完整（用途 / 用户 / 核心功能 / 界面风格 / 技术方案）
- [ ] `README.md` 的「作品信息」表已填写
- [ ] 所有第三方开源组件已在 `docs/作品说明.md` 中标注（名称 / 版本 / 许可 / 来源）
- [ ] 仓库为**公开**仓库，且默认分支上有最新代码

## 二、码道使用痕迹自检（硬性材料）

- [ ] `01-ide-plugin-logs/` —— IDE 插件使用日志与操作记录
- [ ] `02-ai-prompts/` —— AI 交互对话与 Prompt 截图（关键 Prompt 与回复成对保存）
- [ ] `03-codegen-history/` —— 代码生成、重构、排错过程记录
- [ ] 截图清晰可读，文件名带序号与日期，能看出是**本项目**的开发过程
- [ ] 无个人隐私、密钥、他人版权内容出现在痕迹材料中

## 三、打包与命名

- [ ] 压缩包命名：`作品名称+队伍名称+版本号+联系方式.zip`
  - 示例：`智慧校园助手+星火队+v1.0+13800000000.zip`
- [ ] 压缩包内含：源码 + README + 文档 + 痕迹材料
- [ ] 压缩包内**不含** `node_modules/`、`.env`、密钥、构建产物（见 `.gitignore`）

## 四、平台动作

- [ ] GitCode 上已新建**公开**仓库，项目已推送至默认分支，仓库地址已记录
- [ ] 已通过发布 Skill 将作品发布至华为云开发者作品展览馆
      「华为开发者大赛-珠海科技学院校赛」活动专区
- [ ] 已在大赛官网作品提交入口上传压缩包
- [ ] 已查看提交状态与初步审核结果
