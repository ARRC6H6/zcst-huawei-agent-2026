## 二、作品用途与目标用户

- **用途**：解决大学生做生化实验时「实验流程记不全、现象数据记在纸上、实验报告从零写」三件反复消耗时间的事。
  把实验流程沉淀成一份结构化的、可复用的流程文件，实验时按步骤播放并随手记录，结束后一键产出规范格式的实验报告参考版。
- **主要用户**：大学生化类课程的在校学生（化学 / 生物 / 生化方向）；以及需要给学生下发标准化实验流程的实验课教师、助教。
- **使用场景**：
  1. **课前预习 / 教师下发**：在编辑模式里把每个反应步骤的文字、图片、反应方程式、安全 TIPS 写清，并在画布上把仪器摆放摆出来，合并成一份 `.json` 流程文件发给同学。
  2. **课上记录**：打开流程文件切到记录模式，逐步播放；每做一步就写现象与数据、拍图存档，整场异常写进总记录。
  3. **课后成文**：把分步记录与总记录交给 LLM（用户自接 API）生成实验报告参考版；没有 API 也能本地生成规范的 markdown 表格报告，复制或导出 `.md`。
  4. **复习与复盘**：多实验卡片管理，历史实验流程可复制、可导出、可跨设备传递。

## 三、核心功能

1. **多实验管理**：新建 / 复制 / 删除 / 导入 / 导出实验；卡片列表显示学科配色、步骤数与最近更新时间；导出即得到可分享的 `.json` 实验文件。
2. **编辑模式（五要素 + 仪器画布）**：每个反应步骤可写「文字描述 / 图片 / 视频 / 反应方程式 / 安全小 TIPS」；每步各有一张仪器摆放画布，支持从 36 件生化仪器库中拖拽摆放，并可拖移（10px 网格吸附）、缩放（0.4–2.5×）、旋转（15° 步进）、复制、删除、置顶置底、连线与清空，全部走 Pointer Events，一套代码兼容鼠标与触摸。
3. **记录模式（逐步播放 + 两类记录）**：按已编辑文件只读播放，上一步 / 下一步 / 点圆点跳步；播放当前步时可就该步写「现象 / 数据」并追加图片（分步记录），整场备注与异常写进「总记录」。
4. **实验报告（LLM 可选接入，永远有兜底）**：内置面向高校生化报告规范的提示词模板，按 OpenAI 兼容协议把实验数据 JSON 发给用户自配的 LLM，生成中文 markdown 报告参考版；未配置 API Key 或请求失败时自动降级为本地生成的 markdown 表格报告，可复制、可导出 `.md`。
5. **三端自适应与浅色 / 深色**：桌面与平板横向双栏、手机（≤860px）单栏 + 底部 Tab；主题支持浅色 / 深色 / 跟随系统三态，全站走同一套设计令牌，无残留白块。

## 四、界面风格

- **风格定位**：柔光玻璃拟态（glassmorphism）+ 马卡龙六色，参考「鲸鱼便签 Whale Notes」的视觉基准。
- **配色**：六色马卡龙令牌 `t-paper` 云白 / `t-mint` 薄荷 / `t-peach` 蜜桃 / `t-lavender` 薰衣草 / `t-lemon` 柠檬 / `t-sky` 天空，每色四件套（`--tint` / `--tint-2` / `--tint-line` / `--tone`）。
  功能配色固定对应：实验列表 = 云白、编辑模式 = 天空、记录模式 = 蜜桃、实验报告 = 柠檬、设置 = 薰衣草；学科配色：化学 = 天空、生物 = 薄荷、生化 = 薰衣草。
- **文字与形状**：近黑文字 `#1a1f33`，圆角 `--r-window 15px` / `--r-card 13px`，玻璃面用 `backdrop-filter: saturate(180%) blur(20px)` + 158° 渐变 + 带蓝投影。
- **动效**：全站单一缓动 `cubic-bezier(0.16, 1, 0.3, 1)`，禁用 `linear` / `ease`。
- **图标**：全部为内联 SVG 线稿（`stroke-width: 1.8` / `currentColor`），不引任何图标库。
- **移动端**：正文 ≥ 14px、触控目标 ≥ 44px、`hover` 一律补 `:active` 等价反馈。
- 截图见 `docs/images/`。

## 五、技术方案

| 项目 | 内容 |
| --- | --- |
| 技术栈 | 原生 HTML5 + CSS3 + ES2017 JavaScript（**无框架、无构建、无第三方依赖**） |
| 运行环境 | 任意现代浏览器（Chrome / Edge / Firefox / Safari）；桌面、平板、手机三端自适应 |
| 依赖安装 | **无需安装任何依赖**（零 npm、零 CDN、零外链） |
| 启动命令 | 双击 `src/index.html` 即可（也可用任意静态服务器托管） |
| 默认端口 / 访问地址 | 无端口；`file://` 直接打开，或 `http://localhost:8080/src/` |
| 数据存储 | localStorage（实验 / 报告 / 主题 / LLM 配置）+ IndexedDB（图片 Blob，db `zhbit-lab` / store `media`） |
| 自检命令 | `node src/tools/check-page.mjs src/index.html`（86 项自动校验，需全绿） |

### 复现步骤

```bash
# 1. 克隆仓库（公开仓库）
git clone https://github.com/ARRC6H6/zcst-huawei-agent-2026.git
cd zcst-huawei-agent-2026

# 2. 安装依赖 —— 没有依赖，跳过

# 3. 启动：直接双击打开（Windows）
start src/index.html
# macOS: open src/index.html
# Linux:  xdg-open src/index.html

# 可选：用静态服务器托管
python -m http.server 8080
# 然后浏览器访问 http://localhost:8080/src/

# 4. 跑验收自检（需要 Node.js，仅用于校验，应用本身不依赖 Node）
node src/tools/check-page.mjs src/index.html
# 期望输出：共 86 项，通过 86，失败 0
```

### 设计要点

- **单文件交付**：HTML / CSS / JS 全部内联在一个文件里，评委复现成本为零，不存在「装不上环境」的失败路径。
- **数据即文件**：`.json` 是跨端唯一交换格式（`kind: "zhbit-lab-experiment"` / `"zhbit-lab-backup"`），
  原生端未来只需实现同一 schema 的读写即可接管。
- **美术可替换接口**：仪器库 `INST_LIB` 每条的 `imageUrl` 是预留的替换接口 ——
  内联 SVG 只是占位，美术资源到位后逐个填 `imageUrl` 即可，**渲染函数 `renderInstIcon()` 是唯一入口，画布逻辑一行都不用改**。
- **降级优先**：存储层永不抛异常；IndexedDB 不可用时图片自动降级为外部引用；LLM 不可用时降级本地 markdown。
  单文件应用没有第二道防线，所有失败路径都必须是「能继续用」。
- **可验证**：`src/tools/check-page.mjs` 用最小 DOM 桩在 Node 里直接执行页面内联脚本，
  对数据模型、持久化、画布动作、五个视图渲染、报告生成、注入防护、令牌完整性、路由回落、单文件形态做 86 项断言。

## 七、码道使用说明

- 核心 AI 编程工具：**华为云码道 CodeArts**。
- 码道在开发中承担的工作：
  1. 单文件工程骨架与 13 个代码区段的生成；
  2. 数据层 `Store` / `Media`（localStorage + IndexedDB）的编写与降级路径补齐；
  3. 仪器库 36 条内联 SVG 占位图标与画布 Pointer Events 交互（拖拽 / 缩放 / 旋转 / 连线）的实现；

  6. 排错：坏 JSON 白屏、注入转义、深色令牌缺覆盖等问题的定位与修复；
  7. 自动校验脚本 `src/tools/check-page.mjs` 的 86 项断言编写（用码道生成断言、人工复核判定条件）。
