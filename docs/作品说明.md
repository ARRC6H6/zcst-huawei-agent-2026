## 二、作品用途与目标用户

- **用途**：解决大学生做生化实验时「实验流程记不全、现象数据记在纸上、实验报告从零写」三件反复消耗时间的事。
  把实验流程沉淀成一份结构化的、可复用的流程文件，实验时按步骤播放并随手记录，结束后一键产出规范格式的实验报告参考版。
- **主要用户**：大学生化类课程的在校学生（化学 / 生物 / 生化方向）；以及需要给学生下发标准化实验流程的实验课教师、助教。
- **使用场景**：
  1. **课前预习 / 教师下发**：在编辑模式里把每个反应步骤的文字、图片、反应方程式、安全 TIPS 写清，并为**每个步骤单独预置计时器的模式与时长**，合并成一份 `.json` 流程文件发给同学。
  2. **课上记录**：打开流程文件切到记录模式，逐步播放；每做一步就写现象与数据、拍图存档，整场异常写进总记录。
  3. **课后成文**：把分步记录与总记录交给 LLM（用户自接 API）生成实验报告参考版；没有 API 也能本地生成规范的 markdown 表格报告，复制或导出 `.md`。
  4. **复习与复盘**：多实验卡片管理，历史实验流程可复制、可导出、可跨设备传递。
  5. **同学间 / 手机↔电脑互传**：实验课上常出现「现象照片在手机上、报告在电脑上写」的割裂。
     打开「局域网互传」页，同一 Wifi 下手机与电脑可以互传图片、课件与文本，大文件自动分片续传，
     数据只在本机局域网流动、不经任何云盘或第三方服务。

## 三、核心功能

1. **多实验管理**：新建 / 复制 / 删除 / 导入 / 导出实验；卡片列表显示学科配色、步骤数与最近更新时间；导出即得到可分享的 `.json` 实验文件。
2. **AI 生成实验步骤**：把老师发的课件（`.ppt` / `.pptx` / `.doc` / `.docx` / `.txt` / `.md`）交给大模型，一键生成可编辑的实验文件（自动分步、配学科配色、保留用量与时间细节）；也提供「复制提示词 → 任意大模型对话 → 粘贴返回 JSON」的**离线通路**，不依赖任何固定服务商。
3. **编辑模式（五要素）**：每个反应步骤可写「文字描述 / 图片 / 视频 / 反应方程式 / 安全小 TIPS」，并可为**这一步**单独预置计时器的模式与时长。
   > ⛔ 早期版本的「仪器摆放画布 + 36 件仪器库」已按需求整体移除（2026-10-07），不再是本作品的功能。
4. **反应方程式输入器（所见即所得）**：内置元素周期表点选、条件工具栏（箭头 / 可逆 / 加热 / 催化剂 / 沉淀 / 气体 / 同位素 / 括号…）、实时 **KaTeX + mhchem** 化学式渲染与配平校验，历史记录自动留存；**同位素质量数按核素符号规范渲染在元素符号左上角**（`¹⁸O` / `¹⁴C` / `²H`），与离子电荷上标（`Fe³⁺`）互不干扰。
5. **记录模式（逐步播放 + 两类记录）**：按已编辑文件只读播放，上一步 / 下一步 / 点圆点跳步；播放当前步时可就该步写「现象 / 数据」并追加图片（分步记录），整场备注与异常写进「总记录」。
6. **实验报告（LLM 可选接入，永远有兜底）**：内置面向高校生化报告规范的提示词模板，按 OpenAI 兼容协议把实验数据 JSON 发给用户自配的 LLM，生成中文 markdown 报告参考版；未配置 API Key 或请求失败时自动降级为本地生成的 markdown 表格报告，可复制、可导出 `.md`。
7. **局域网互传（同一 Wifi 内，数据不经云端）**：一键启动零依赖服务端后，手机 / 平板 / 电脑用浏览器互传**文件与文本**；支持多文件拖拽、实时进度与速度、大文件 4MB 分片 + 断点续传 + 同一文件秒传、共享文件列表下载 / 删除。两种进入方式都通：直接打开服务端地址（同源自动连接），或双击本机 HTML 后手填服务端地址（服务端已开 CORS，地址会被记住）。手机端页面**支持双指缩放**，清单与地址可放大看清。
8. **下载即导入（点下载 = 导入开关，接收端同样生效）**：在共享文件列表里点**「下载」**时，若文件是实验 `.json`（本应用实验包 / 「导出全部实验」备份包 / AI 生成的裸实验 JSON），会**同时自动加进本机的「我的实验」**，名字标注「（互传导入）」、一律分配新 id（不覆盖本机已有实验）；图片、文档、视频等非 `.json` 完全不处理；认不出的 `.json` 会在**互传页「下载即导入」卡片、首页红色横幅与提示条**三处明确报错，不会悄悄吞掉。谁下载谁导入，电脑与手机（接收端）都生效；**不做任何后台监听与轮询**，点下载才是触发键；同一文件重复下载只会提示「之前已导入过」。
9. **计时器（每步一个 + 记录模式的自由计时器）**：**每个步骤各有一个独立计时器**，编辑模式为当前步预设「正计时 / 倒计时」与目标时长（30s / 1 / 2 / 5 / 10 / 30min 六个快捷预设 + 自定义分秒），记录模式播放到该步时手动**开始 / 暂停 / 继续 / 归零 / 记一次**；倒计时到点蜂鸣 + 震动并在提示条报时，同时把 `[计时] 倒计时结束 MM:SS` 自动写进**这一步**的「现象 / 数据」。记录模式另有一条**不绑定任何步骤的自由计时器**，卡上即可随时改模式与时长、随时启停 —— 适合整场实验的通用计时；它到点只响铃、**不写步骤记录**。多条计时器可以**同时运行**、互不干扰；计时状态随实验保存（切页面或重启都继续走）。用过计时器时，实验报告会自动多出「计时」章节，并**逐步列出**各步计时器与自由计时器。
10. **三端自适应与浅色 / 深色**：桌面与平板横向双栏、手机（≤860px）单栏 + 底部 Tab（7 个页面）；主题支持浅色 / 深色 / 跟随系统三态，全站走同一套设计令牌，无残留白块；手机端页面允许双指缩放（浏览器侧靠 viewport，打包成 Android App 时由 WebView 内置缩放提供）。

## 四、界面风格

- **风格定位**：柔光玻璃拟态（glassmorphism）+ 马卡龙六色，参考「鲸鱼便签 Whale Notes」的视觉基准。
- **配色**：六色马卡龙令牌 `t-paper` 云白 / `t-mint` 薄荷 / `t-peach` 蜜桃 / `t-lavender` 薰衣草 / `t-lemon` 柠檬 / `t-sky` 天空，每色四件套（`--tint` / `--tint-2` / `--tint-line` / `--tone`）。
  功能配色固定对应：实验列表 = 云白、AI生成实验步骤 = 薄荷、编辑模式 = 天空、记录模式 = 蜜桃、实验报告 = 柠檬、局域网互传 = 薄荷、设置 = 薰衣草；学科配色：化学 = 天空、生物 = 薄荷、生化 = 薰衣草。
- **文字与形状**：近黑文字 `#1a1f33`，圆角 `--r-window 15px` / `--r-card 13px`，玻璃面用 `backdrop-filter: saturate(180%) blur(20px)` + 158° 渐变 + 带蓝投影。
- **动效**：全站单一缓动 `cubic-bezier(0.16, 1, 0.3, 1)`，禁用 `linear` / `ease`。
- **图标**：全部为内联 SVG 线稿（`stroke-width: 1.8` / `currentColor`），不引任何图标库。
- **移动端**：正文 ≥ 14px、触控目标 ≥ 44px、`hover` 一律补 `:active` 等价反馈。

## 五、技术方案

| 项目 | 内容 |
| --- | --- |
| 技术栈 | 原生 HTML5 + CSS3 + ES2017 JavaScript（**无框架、无构建、无外链**）；内联 React / KaTeX / mhchem 仅用于化学方程式输入器 |
| 可选服务端 | `src/lan-server.py`：Python 3.7+ **标准库**实现（`http.server` 等），零第三方依赖、无需 `pip install`，仅服务「局域网互传」 |

### 设计要点

- **单文件交付**：HTML / CSS / JS 全部内联在一个文件里，评委复现成本为零，不存在「装不上环境」的失败路径。
- **数据即文件**：`.json` 是跨端唯一交换格式（`kind: "zhbit-lab-experiment"` / `"zhbit-lab-backup"`），
  原生端未来只需实现同一 schema 的读写即可接管。
- ~~美术可替换接口~~：⛔ 早期为仪器库预留的 `imageUrl` / `renderInstIcon()` 替换接口**已随「仪器摆放」一并移除**（2026-10-07）。
- **计时器模型**：`step.timer`（每步一个）+ `exp.timer`（不绑定步骤的自由计时器）同构；
  动作靠 DOM 上的 **`data-timer-src`** 路由（`"free"` / 步号），由 `resolveTimer()` 统一解析 ——
  加新按钮时不必改分发逻辑，只把它放进带该属性的卡片里即可。
- **旧数据兼容**：计时器字段名沿用 `exp.timer`，`migrateTimers()` 会**幂等**地把旧版「整场一个」的
  计时器下放到第一步，同时保留一份作为自由计时器，老实验的用户数据不会丢。
- **降级优先**：存储层永不抛异常；IndexedDB 不可用时图片自动降级为外部引用；LLM 不可用时降级本地 markdown；
  互传服务端没启动或连不上时，「局域网互传」页只显示启动引导，**其余六个页面完全不受影响**。
  单文件应用没有第二道防线，所有失败路径都必须是「能继续用」。
- **化学式渲染可信**：`smartConvert()` 统一规范写法（`^18O`、`O^18`、`H2O^18`、`C^14O2` 都渲染成元素左上角的质量数），
  mhchem 负责排版，`parseFormula()` 剥离质量数保证配平不受同位素影响；`check-isotope.mjs` 用真实 KaTeX 渲染结果断言位置。
- **可验证**：三套脚本都是「真跑」而非静态检查 —— `check-page.mjs` 用最小 DOM 桩在 Node 里直接执行页面内联脚本；
  `check-isotope.mjs` 抽出内联库真跑规范化与渲染；`check-lan.mjs` **真启动 Python 服务端**跑完整接口链路。

## 七、码道使用说明

- 核心 AI 编程工具：**华为云码道 CodeArts**。
- 码道在开发中承担的工作：
  1. 单文件工程骨架与各代码区段的生成；
  2. 数据层 `Store` / `Media`（localStorage + IndexedDB）的编写与降级路径补齐；
  3. **计时器**：状态机（正计时 / 倒计时、累计、记一次、蜂鸣震动、到点写记录）与
     「每步一个 + 自由计时器」的挂载、`data-timer-src` 动作路由、旧数据幂等迁移；
  4. 各视图的渲染与哈希路由、`data-act` 事件委托的重构收敛；
  5. 报告提示词模板 `REPORT_PROMPT` 与本地 markdown 兜底生成的迭代；
  6. **化学方程式输入器**：参考 `chem-input` 源工程构建为自包含产物后内联进单文件，
     并补上同位素质量数规范化（`^18O` / `O^18` 一律渲染为元素左上角）与回归断言；
  7. **AI 生成实验步骤页**：课件文本抽取（docx/pptx 走内联 ZIP、旧版 doc/ppt 直读 OLE2）、
     生成提示词 `GEN_PROMPT`、JSON 容错解析与落地校验；
  8. **局域网互传页 + 零依赖 Python 服务端**：接口设计（指纹即 id、分片原子落盘、缺片拒绝合并）、
     前端分片上传 / 断点续传 / 秒传 / 局部重绘轮询，以及端到端校验脚本；
  9. **记录模式计时器与互传「下载即导入」**：把参考工程 `实验助手-计时模块` 的状态机（正计时 / 倒计时、
      累计、记一次、蜂鸣）改挂到「整场实验」上，补齐编辑模式预设与「到点自动写入当前步记录」；
      以及把互传导入从「后台监听服务端目录」改成「点下载即导入」（三种实验 JSON 形态识别、去重表、
      非 .json 不处理、三处错误提示），并修好手机 App 里 WebView 默认禁用的双指缩放；
  10. 排错：坏 JSON 白屏、注入转义、深色令牌缺覆盖、同位素与离子电荷上标混淆、
      「到点只响一次」因对象被反复重建而失效等问题的定位与修复；
  11. 四套自动校验脚本的断言编写（用码道生成断言、人工复核判定条件）。
- 岗位分工与对表流程见 [`工作须知.md`](工作须知.md)，冻结的接口契约见 [`../skills/pair-dev-contract/SKILL.md`](../skills/pair-dev-contract/SKILL.md)。
- 痕迹材料位置：见 [`.evidence/`](../.evidence/README.md)。
