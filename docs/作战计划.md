## 6. 分工

| 谁 | 负责 |
| --- | --- |
| **老师** | 拍板选题、方向、审美、UI 取舍；组队与对外沟通（队友、指导老师、赛事群）；答辩 |
| **大叔（助手）** | 调研选题、写代码、跑验证、写文档、整理痕迹材料、盯时间节点、提前踩发布流程的坑 |

**协作约定**：
- 方向性选择（选题、要不要砍功能）→ 必须先问老师
- 执行性工作（写代码、查资料、跑脚本）→ 大叔主动推进，不等着喂指令
- 老师只负责「做决定」，不负责「记住细节」—— 细节大叔会盯

| 队友掉链子/组不满队 | 中 | 大 | 10/02 前必须定死；实在不行 2 人也能报（下限 2 人） |
| 发布流程卡住（hcloud/AK/SK/展览馆） | 中 | 大 | **10/22 提前试跑一遍**，别留到最后一天 |
| 国庆假期作息崩 | 中 | 中 | 攻坚期目标别定太满，留 1 天机动 |
| 作品跑不起来（评委复现失败） | 中 | 致命 | 10/20 在一台干净环境走一遍 README 的启动步骤 |
| 每天只有 1 次提交机会 | 低 | 中 | 攒够改动再交；提交前先跑通「提交前自检」 |
